    GPU / Interconnect / NCCL Pre-Demo Health Check¶

    A 2-minute end-to-end checklist using vendor CLI tools. Copy-paste ready.

    1) HBM / GPU Health Snapshot (every 5s)¶

    nvidia-smi --query-gpu=timestamp,name,pci.bus_id,driver_version,pstate,pcie.link.gen.max,pcie.link.gen.current,temperature.gpu,utilization.gpu,utilization.memory,memory.total,memory.free,memory.used --format=csv -l 5

    2) Interconnect Topology (NVLink / NVSwitch / PCIe)¶

    nvidia-smi topo -m

    3) Short Runtime Probe with Nsight Systems (10s window)¶

    nsys profile --stats=true -t nvtx,cuda,osrt --delay=1 --duration=10 -o quick_check ./your_server_binary_or_start_script

    4) NCCL Smoke Test (intra-node all-reduce)¶

    # build nccl-tests first; -g = GPUs per node
./build/all_reduce_perf -b 8 -e 128M -f 2 -g <num_gpus_on_node>

    5) Network Fabric Sanity (optional — NIC/RDMA/IP path)¶

    # Server
iperf3 -s
# Client (parallel 8 streams for 10s)
iperf3 -c <server-ip> -P 8 -t 10

    Pass / Fail Guide¶

    HBM / NVML¶

    • PASS: memory.total ~ expected HBM size, memory.free > ~5-10% when idle, utilization.gpu rises under load, nvidia-smi -q -d ECC shows 0 errors
    • FAIL: NVML init errors, non-zero ECC counts, memory.total far below expected

    Interconnect / NCCL¶

    • PASS: nvidia-smi topo -m shows NVLink/NVSwitch between GPUs you'll use; all_reduce_perf completes with stable bandwidth in expected ballpark
    • FAIL: Hangs, NCCL_ERROR, bandwidth stuck near zero or PCIe-only unexpectedly

    Container / Runtime¶

    • PASS: nsys shows CUDA kernels during capture; nvidia-smi works inside the container
    • FAIL: No GPU activity during supposed serving; NVML fails to init (driver/runtime or cgroup mismatch)

    Network (optional)¶

    • PASS: iperf3 throughput >= ~90% of link-rate with low reordering/loss
    • FAIL: Throughput << link capacity or unstable

    Quick Fixes¶

    • NVML/init issues — verify host driver matches container runtime (NVIDIA Container Toolkit), check cgroups and device visibility
    • NCCL low BW/hangs — rerun with NCCL_DEBUG=INFO, confirm topology with nvidia-smi topo -m, sanity-check NIC/fabric; grab one 10s nsys profile to spot send_wait stalls
