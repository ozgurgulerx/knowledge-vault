    Reinforcement Learning: Principles, Methods, and Frontiers¶

    Opening Briefing¶

    Reinforcement learning's central paradox is not exploration versus exploitation — that tension is well-characterized and has mature solutions. The deeper structural problem is that RL's most celebrated successes and its most stubborn failures share the same root cause: the reward signal simultaneously defines the objective, shapes the learning dynamics, and gates the credit assignment pathway. When reward is dense and well-specified, as in board games with binary win/loss outcomes, RL produces superhuman performance. When reward is sparse, misspecified, or requires human judgment, the entire framework strains under a burden it was never designed to carry alone.

    This dual nature of reward explains the field's two most consequential developments. First, model-based methods like MuZero and DreamerV3 achieve order-of-magnitude improvements in sample efficiency not primarily because they "plan ahead," but because a learned world model provides a second channel for credit assignment — the agent can attribute outcomes to state transitions rather than relying solely on reward backpropagation through temporal-difference chains. MuZero's ability to reach superhuman play in Go, chess, and Atari without knowing game rules demonstrates that learning the dynamics is strictly more powerful than learning the value function alone, because dynamics implicitly encode reward structure. Second, RLHF resolves reward misspecification by replacing hand-crafted scalar signals with a learned reward model trained on human preference comparisons — effectively outsourcing the hardest part of RL (defining what "good" means) to a supervised learning problem. The fact that InstructGPT, a 1.3B parameter model fine-tuned with RLHF, was preferred over the 175B GPT-3 reveals that alignment through reward modeling can substitute for a 100x increase in model capacity.

    The implication is that RL's frontier is no longer primarily about better optimization algorithms. PPO's clipped surrogate, SAC's entropy regularization, and TD3's twin critics are refinements within a mature optimization paradigm. The binding constraints have shifted to reward specification and sample efficiency — how to define what the agent should optimize, and how to extract maximum learning from minimal interaction. Offline RL, causal RL, and meta-RL each attack one face of this compound problem: learning without interaction, learning what transfers across tasks, and learning how to learn faster.

    This document maps the full technical landscape from Bellman equations through multi-agent game theory to RLHF-based language model alignment, treating each method not as an isolated algorithm but as a specific response to the reward-credit-efficiency trilemma. The accompanying mastery plan structures this progression into 14 weeks of implementation-driven study, ensuring that theoretical understanding is anchored in working code at every stage.

    Foundations¶

    Agent-Environment Interaction Loop¶

    An agent observes state S_t, takes action A_t, receives reward R_{t+1}, and transitions to S_{t+1}. Goal: maximize cumulative reward (return). Formally modeled as a Markov Decision Process (MDP): tuple (S, A, P, R, gamma) where P(s'|s,a) is transition probability, R(s,a,s') is reward, gamma in [0,1) is discount factor. Markov property: next state depends only on current state and action.

    States, Observations, Actions¶

    • State S_t: complete environment description (or partial observation O_t in POMDPs)
    • Action space: discrete (board games, Atari) or continuous (robot torques)
    • Policy pi: mapping from states to actions — deterministic pi(s)=a or stochastic pi(a|s)

    Rewards, Returns, Value Functions¶

    • Return G_t = R_{t+1} + gamma*R_{t+2} + ... = sum(gamma^k * R_{t+k+1})
    • State-value function V^pi(s) = E[G_t | S_t=s] under policy pi
    • Action-value function Q^pi(s,a) = E[G_t | S_t=s, A_t=a] under policy pi
    • Bellman equation: V^pi(s) = sum_a pi(a|s) sum_s' P(s'|s,a)[R(s,a,s') + gamma*V^pi(s')]
    • Bellman optimality: V(s) = max_a sum_s' P(s'|s,a)[R(s,a,s') + gammaV*(s')]

    Key: If we have Q, an optimal policy is obtained by choosing actions that maximize Q(s,a) in each state (greedy policy).

    Key Mathematical Formulations¶

    Dynamic Programming (known model)¶

    • Policy Iteration: alternate policy evaluation (solve V^pi) and policy improvement (greedy w.r.t. V^pi). Converges to optimal policy
    • Value Iteration: directly apply Bellman optimality updates until convergence, then extract policy

    Model-Free: Q-Learning and SARSA¶

    • Q-learning (Watkins 1989): off-policy TD algorithm. Update: Q(s,a) <- Q(s,a) + alpha[r + gammamax_a' Q(s',a') - Q(s,a)]. Can learn Q while following exploratory policy (epsilon-greedy). TD error delta = r + gamma*max_a' Q(s',a') - Q(s,a)
    • SARSA: on-policy. Update: Q(s,a) <- Q(s,a) + alpha[r + gamma*Q(s',a') - Q(s,a)] where a' is the action actually taken. Learns Q of the policy being followed — more conservative/safer than Q-learning

    Policy Gradient Methods¶

    • Directly optimize policy pi_theta(a|s) by gradient ascent on expected return J(theta)
    • Policy gradient theorem: nabla J(theta) = E[nabla log pi_theta(a|s) * Q^pi(s,a)]
    • REINFORCE (Williams 1992): use sampled returns G_t as unbiased estimate. High variance
    • Actor-Critic: actor = policy pi_theta, critic = value function V_w. Critic provides lower-variance advantage estimates
    • Advantage Actor-Critic (A2C): uses TD error delta_t = r + gamma*V(s_{t+1}) - V(s_t) as advantage estimator

    Function Approximation & Deep RL¶

    • Replace tables with parameterized functions (neural networks) for Q or pi
    • Significance: (1) handles enormous state spaces, (2) enables generalization, (3) brings efficiency to continuous/high-dimensional domains
    • DQN (DeepMind, 2015): CNN approximates Q-function for Atari from pixels. Key innovations: experience replay + target networks
    • Deadly triad: function approximation + bootstrapping + off-policy can cause instability

    Model-Based vs Model-Free¶

    Criterion Model-Based Model-Free
    Requires model? Yes (given or learned) No — learns from trial-and-error
    Sample efficiency High — can simulate/plan internally Often low — needs many interactions
    Planning Multi-step lookahead (search, DP) No explicit planning — reactive
    Bias vs variance Model bias if inaccurate No model bias; higher variance
    Compute cost Planning expensive in large spaces Heavy training, simpler per-step
    Examples AlphaGo/AlphaZero (MCTS), MPC DQN, Policy Gradient, locomotion
    • Hybrid: Dyna algorithm (Sutton) — learn model, use for limited lookahead + model-free learning
    • MuZero (DeepMind): learns model implicitly, superhuman in Go/chess/Atari without knowing rules

    Key: Modern research combines both — model-free policy + model-based planning.

    Core Challenges¶

    Exploration vs Exploitation¶

    • epsilon-greedy: explore with probability epsilon, exploit with 1-epsilon
    • UCB: balance estimated mean + exploration bonus
    • Thompson Sampling: sample from posterior over reward distributions
    • Intrinsic motivation / curiosity: reward for visiting novel states
    • Hardest in environments with sparse rewards — reward shaping and hierarchical RL help

    Credit Assignment¶

    • Temporal: which past actions caused the eventual reward? TD errors propagate signal backwards; eligibility traces (TD(lambda)) smooth credit assignment
    • Structural: attributing outcomes to network parameters or multi-agent contributions
    • Remains hard with long horizons and delayed feedback

    RL Variants & Advanced Topics¶

    Deep RL (DRL)¶

    • Value-based: DQN, Double DQN, Dueling DQN
    • Policy-based: DDPG, TRPO, PPO
    • Actor-Critic: A2C/A3C, SAC, TD3
    • Games: AlphaGo (2016, world champion Go), AlphaZero, AlphaStar (StarCraft II), OpenAI Five (Dota 2)
    • Robotics: OpenAI Dactyl — 5-fingered hand solves Rubik's Cube, trained entirely in simulation
    • Data center cooling: Google DeepMind achieved 40% energy reduction; fully autonomous by 2018, ~30% consistent savings

    Multi-Agent RL (MARL)¶

    • Stochastic/Markov Games with N agents, joint actions, different rewards
    • Cooperative: value factorization (QMIX), shared reward, centralized training + decentralized execution
    • Competitive: Nash equilibria, self-play (AlphaZero, OpenAI Five 5v5 Dota 2)
    • Dec-POMDP: cooperative partial observability — optimally NEXP-hard
    • Challenges: non-stationarity, credit assignment among agents, exponential state-action growth

    Inverse RL (IRL)¶

    • Infer reward function from expert behavior, then derive policy
    • Ng & Russell (2000): "the reward function is the most succinct, robust, and transferable definition of the task"
    • Maximum Entropy IRL (Ziebart 2008): expert trajectories exponentially more likely
    • Underpins RLHF — reward model from human preference judgments
    • Applications: autonomous driving, robot objectives, AI safety/alignment

    Meta-RL¶

    • "Learning to learn": train on task distribution so agent adapts quickly to new tasks
    • Inner loop (solve MDP) + outer loop (optimize learning procedure)
    • Recurrent-based: RNN hidden state implements learning algorithm (RL^2, Wang et al. 2016)
    • Gradient-based: MAML — find initialization that adapts in few gradient steps
    • Applications: robotic manipulation, navigation, automated RL algorithm design (AutoRL)

    Offline RL (Batch RL)¶

    • Learn from fixed dataset without environment interaction
    • For domains where exploration is costly/unsafe: healthcare, autonomous driving
    • Key challenge: distributional shift — actions outside data have unreliable value estimates
    • Solutions: CQL, BCQ (conservative/pessimistic Q-learning)
    • Netflix: modeled recommendation as MDP, used offline RL on logged interactions

    Challenges & Limitations¶

    Challenge Mitigations
    Sample inefficiency Model-based RL, transfer learning, meta-RL, offline RL
    Reward hacking Reward shaping, RLHF, constrained RL, multi-objective
    Safety Safe exploration, safety shields, constrained MDPs, sim-to-real
    Interpretability Policy distillation, attention visualization, rule extraction
    Stability / hyperparameter sensitivity Target networks, clipping (PPO), multiple seeds
    Non-stationarity Online learning, meta-learning, periodic retraining
    Scalability Policy gradients for continuous, recurrent networks for POMDPs

    Future Directions¶

    • Hierarchical RL: options framework, FeUdal networks, goal-conditioned RL — tackle long horizons via temporal abstraction. Notably, hierarchy can also emerge from flat RL training: GRPO-trained LLMs exhibit a two-phase dynamic where procedural skill solidifies before strategic reasoning develops, suggesting that temporal abstraction need not be architecturally imposed but can arise from the structure of the optimization landscape itself
    • Causal RL: counterfactual reasoning, causal exploration, better generalization and transfer (Bareinboim et al.)
    • Generalist agents: Gato (DeepMind, 600+ tasks), foundation models as RL policies, language as latent action space
    • AutoRL / Meta-learning: automated algorithm design, hyperparameter tuning, learning to learn
    • Integration of paradigms: imitation + RL, self-supervised + RL, Decision Transformers ("Upside-down RL"), lifelong learning
    • Multi-agent co-learning: cooperative/competitive AI at scale (smart grids, traffic, trading)
    • Neuro-symbolic RL: hierarchical reasoning with symbolic planners + low-level RL execution
    • Human alignment: RLHF scaling, constrained/safe behavior, embedding norms via LLMs

    Key: RL is heading toward more general, adaptable, and human-aligned agents — combining hierarchical planning, causal reasoning, foundation models, and RLHF.
